Semantics for wh-questions

Semantics for wh-questions🔗

A Model M = \langle W,D,F,C\rangle, where

W is a set of possible worlds,

D=\bigcup\{D^{w} : w\in W\} is a set of individuals,

F is an interpretation function for lexical items, and

C specifies counterpart relations between individuals in different possible worlds.

Variables and indexes range over individual concepts. If they need to denote an individual, a superscript of a possible world is added to them.

Contextual and non-contextual assignments

G is a set of functions from a set of natural numbers

N into a set of semantic entities of various semantic types. (DP normally ranges over individual concepts.)

e.g. \llbracket[t_{i}]_{DP}\rrbracket^{\vec{g}gw} = g(i)^{w}

\vec{G} is a set of functions from N to a set of functions from subsets of G \times W to semantic entities denoted w.r.t. assignment-world pairs in the subsets.

e.g. \llbracket[t^{[+wh]}_{i}]_{DP}\rrbracket^{\vec{g}gw}

= \vec{g}(i), where \vec{g}(i)=\lambda\langle g\prime w\prime \rangle \in \boldsymbol{g}\times\boldsymbol{w}[g\prime (i)^{w\prime }], where

\boldsymbol{g} \subseteq G and \boldsymbol{w} \subseteq W.

The non-contextual value is contextualized within IP.

\vec{g}(i)=\left[\begin{array}{ccc} g_{1}w\prime & \rightarrow & d_{1}(=g_{1}(i)^{w\prime })\\ g_{2}w\prime & \rightarrow & d_{2}(=g_{2}(i)^{w\prime })\\ g_{3}w\prime & \rightarrow & d_{3}(=g_{3}(i)^{w\prime })\\ ... & ... & ... \end{array}\right]

A proper name, an intransitive and a transitive verb

If \alpha is a proper name, \llbracket\alpha\rrbracket^{\vec{g}gw} = F(\alpha)^{w}

e.g. \llbracketJohn\rrbracket^{\vec{g}gw} = F(John)^{w} = jo^{w}

\llbracket[_{IV} \alpha ]\rrbracket^{\vec{g}gw} = \lambda x^w[F(\alpha)^{w}(x^w)];

\llbracket[_{TV} \alpha ]\rrbracket^{\vec{g}gw} = \lambda y^w\lambda x^w[F(\alpha)^{w}(y^w)(x^w)]

A VP is extensional and an IP is intensional.

\llbracket[_{VP} \alpha [[_{V} \gamma ] \beta]]]\rrbracket^{\vec{g}gw} = \llbracket\gamma\rrbracket^{\vec{g}gw}(\llbracket\beta\rrbracket^{\vec{g}gw})(\llbracket\alpha\rrbracket^{\vec{g}gw})

\llbracket[_{IP} ^\alpha ]\rrbracket^{\vec{g}gw} = \lambda w\prime \llbracket \alpha \rrbracket^{\vec{g}gw\prime }

A quantifier

If Q is a quantificational determiner,

\llbracket[[_{DP} Q \alpha ]_{i} \beta ]\rrbracket^{\vec{g}gw} = [\llbracket Q\rrbracket^{\vec{g}gw}(\llbracket\alpha\rrbracket^{\vec{g}gw})(\lambda x[\llbracket\beta\rrbracket^{\vec{g}g[i/x]w}])].

A wh-word generates a set of alternatives and a wh-DP has the [+wh] feature as a specific indefinite.

\Rightarrow a set of non-contextual values with the existential force and descriptive content presupposed.

The scope of a wh-DP is determined by presupposition projection.

\llbracket[_{DP} which^{[+wh]} \alpha]^{[+wh]}_{i}\rrbracket^{\vec{g}gw}

= \lambda\langle g\prime w\prime \rangle\llbracket[_{DP} which^{[+wh]} \alpha]_{i}\rrbracket^{\vec{g}g\prime w\prime }

= \{\lambda\langle g\prime w\prime \rangle[\ll\pi\gg \vec{x}^{g\prime [i/y]w\prime }] : \vec{x}\in Alt(\vec{g}(i))\}

\pi = \lambda \langle g\prime w\prime \rangle \exists y[\llbracket\alpha\rrbracket^{\vec{g}g\prime [i/y]w\prime }(\vec{x}^{g\prime [i/y]w\prime })], where g\prime [i/y]w\prime is in the domain of \vec{x}.

\pi is accommodated in a linguistic context g\prime \prime w\prime \prime in the following way:

\pi(\langle g\prime \prime w\prime \prime \rangle) \Rightarrow \lambda \langle g\prime w\prime \rangle \exists y^w[\llbracket\alpha\rrbracket^{\vec{g}g\prime [i/y]w\prime }(\vec{x}^{g\prime [i/y]w\prime })](\langle g\prime \prime w\prime \prime \rangle)

= \exists y^w[\llbracket\alpha\rrbracket^{\vec{g}g\prime \prime [i/y]w\prime \prime }(\vec{x}^{g\prime \prime [i/y]w\prime \prime })]

who = which person;

where = which place;

when = which time (which here is number-neutral)

Depending on whether each of the two daughters denotes a set of meanings, the whole expression can denote a set of meanings based on the following rules:

\llbracket[_{\gamma} \alpha \beta]\rrbracket^{\vec{g}gw} =

i) \{\ll\pi_{1},\pi_{2}\gg C : \vec{x}\in Alt(\vec{g}(i)),\vec{y}\in Alt(\vec{g}(j))\} if \llbracket\alpha\rrbracket^{\vec{g}gw} = \{\ll\pi_{1}\gg A : \vec{x}\in Alt(\vec{g}(i))\} & \llbracket\beta\rrbracket^{\vec{g}gw}=\{\ll\pi_{2}\gg B : \vec{y}\in Alt(\vec{g}(j))\};

ii) \{\ll\pi\gg C : \vec{x} \in Alt(\vec{g}(i))\} if \llbracket\alpha\rrbracket^{\vec{g}gw} = \{\ll\pi\gg A : \vec{x}\in Alt(\vec{g}(i))\} & \llbracket\beta\rrbracket^{\vec{g}gw}=B;

iii) C, if \llbracket\alpha\rrbracket^{\vec{g}gw} = A and \llbracket\beta\rrbracket^{\vec{g}gw}=B.

(C=A(B) or B(A), depending on the semantic types of \alpha and \beta.)

The interrogative Mood takes a proposition (or a set of propositions) and yields a pair of an affirmative and negative proposition (or a set of pairs of an affirmative and negative proposition).

\llbracket[ M_{[Q]} [_{IP} \alpha]]\rrbracket^{\vec{g}gw} =

i) \langle\lambda w\prime \llbracket\alpha\rrbracket^{\vec{g}gw\prime },\lambda w\prime [\neg\llbracket\alpha\rrbracket^{\vec{g}gw\prime }]\rangle, if \alpha includes no wh-phrase;

ii) \{\langle p,\lambda w\prime [\neg p^{w\prime }]\rangle : p\in \llbracket\alpha\rrbracket^{\vec{g}gw}\}, if \alpha includes at least one wh-phrase.

Suppose that \alpha^{[+wh]}_{i} is in the Spec of MP including a wh-word and \beta is an M\prime. Then

\llbracket[_{MP} \alpha^{[+wh]}_{i} [_{M\prime } \beta ]]\rrbracket^{\vec{g}gw} =

i) \{\lambda\vec{y}\llbracket\beta\rrbracket^{\vec{g}[i/\vec{y}]gw}(\vec{x}) : \vec{x}\in\llbracket\alpha^{[+wh]}_{i}\rrbracket^{\vec{g}gw}\} if \beta includes no wh-phrase;

= \{\llbracket\beta\rrbracket^{\vec{g}[i/\vec{x}]gw} : \vec{x}\in\llbracket\alpha^{[+wh]}_{i}\rrbracket^{\vec{g}gw}\}

ii) \{\langle p,\lambda w\prime \neg p^{w\prime }\rangle\in\llbracket\beta\rrbracket^{\vec{g}[i/\vec{x}]gw} : \vec{x}\in\llbracket\alpha^{[+wh]}_{i}\rrbracket^{\vec{g}gw}\} if \beta includes at least one wh-phrase.

A set of pairs of an affirmative and negative proposition is equivalent to a power set of a set of affirmative propositions.

\{\langle p_{1},\lambda w\prime [\neg p^{w\prime }_{1}]\rangle,...,\langle p_{n},\lambda w\prime [\neg p^{w\prime }_{n}]\rangle\} \Rightarrow Pow(\{p_{1},...,p_{n}\})\setminus\emptyset

Compositional interpretation of the functional reading of a wh-question

[_{MP} [_{DP} Who_i^{[+wh]}] [_{M\prime } [_M does]] [_{IP} [_{DP} everyone_j] [_{VP} love t_i^{[+wh]}]]]]

\llbrackett^{[+wh]}_{i} \rrbracket^{\vec{g}gw} = \vec{g}(i) (contextualized with love)

\llbracket t_{j} love t^{[+wh]}_{i} \rrbracket^{\vec{g}gw} = love^{w}(g(j)^w,\vec{g}(i)^{gw})

\llbracket^everyone_{j} [ t_{j} love t^{[+wh]}_{i}]\rrbracket^{\vec{g}gw}

= \lambda w\prime \forall x^{w\prime}[person^{w\prime }(x^{w\prime}) \rightarrow \lambda z^{w\prime}\llbracket[ t_{j} love t^{[+wh]}_{i}]\rrbracket^{\vec{g}g[j/z]w\prime }(x^{w\prime})]

= \lambda w\prime \forall x^{w\prime}[person^{w\prime }(x^{w\prime}) \rightarrow love^{w\prime }(x^{w\prime},\vec{g}(i)^{g[j/x]w\prime })]

\llbracketdoes ^[everyone_{j} [ t_{j} love t^{[+wh]}_{i}]\rrbracket^{\vec{g}gw}

= \langle \lambda w\prime \forall x^{w\prime}[person^{w\prime }(x^{w\prime}) \rightarrow love^{w\prime }(x^{w\prime},\vec{g}(i)^{g[j/x]w\prime })], \lambda w\prime \neg\forall x^{w\prime}[person^{w\prime }(x^{w\prime}) \rightarrow love^{w\prime }(x^{w\prime},\vec{g}(i)^{g[j/x]w\prime })]\rangle

\llbracketWho^{[+wh]}_{i}\rrbracket^{\vec{g}gw} = \llbracket[Which^{[+wh]} person]^{[+wh]}_{i}\rrbracket^{\vec{g}gw} =

\{\lambda\langle g\prime ,w\prime \rangle[\ll\pi\gg\vec{x}^{g\prime [i/y]w\prime }]: \vec{x}\in Alt(\vec{g}(i))\}

\pi: \lambda \langle g\prime \prime w\prime \prime \rangle\exists y^{w\prime\prime}[person^{w\prime \prime }(\vec{x}^{g\prime \prime [i/y]w\prime \prime })]

\llbracketWho^{[+wh]}_{i} does ^[everyone_{j} [ t_j love t^{[+wh]}_{i}]]\rrbracket^{\vec{g}gw} =

\{\lambda \vec{z} \llbracket\hbox{does }[\hbox{everyone}_j [ \hbox{t}_j \hbox{ love t}^{[+wh]}_{i} ]]\rrbracket^{\vec{g}[i/\vec{z}]gw}(\vec{x})| \vec{x}\in \llbracket\hbox{Who}^{[+wh]}_{i}\rrbracket^{\vec{g}gw}\}

= Pow(\{\lambda w\prime \forall x^{w\prime}[person^{w\prime }(x^{w\prime})\rightarrow love^{w\prime }(x^{w\prime},\ll\pi\gg\vec{x}^{g[i/y][j/x]w\prime })]| \vec{x} \in Alt(\vec{g}(i))\})\setminus\emptyset

\Rightarrow Pow(\{\lambda w\prime \forall x^{w\prime}[person^{w\prime }(x^{w\prime}) \rightarrow \ll\pi(\langle g[j/x],w\prime \rangle)\gg love^{w\prime }(x^{w\prime},\vec{x}^{g[i/y][j/x]w\prime })]| \vec{x} \in Alt(\vec{g}(i))\})\setminus\emptyset

\lambda \langle g\prime\prime w\prime \prime \rangle\exists y^{w\prime\prime}[person^{w\prime \prime }(\vec{x}^{g\prime \prime [i/y]w\prime \prime })](\langle g[j/x] w\prime \rangle)

= \exists y^{w\prime}[person^{w\prime }(\vec{x}^{g[j/x][i/y]w\prime })]
