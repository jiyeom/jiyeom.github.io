excerpt: 'A command can be issued with an imperative or an explicit performative with an embedded clause. However, an explicit performative with an embedded imperative is not acceptable. If an imperative is embedded, it becomes a <i>ko</i>-phrase, where <i>ko</i> is a complementizer. If an explicit performative is used as a command, it take a <i>kes</i>-phrase with a modal adnominal ending <i>-(u)l</i>. I claim that a <i>ko</i>-phrase is interpreted as an intensional semantic entity, which makes it possible for a <i>ko</i>-phrase to express a non-realistic content of a command. With a <i>kes</i>-phrase, an explicit performative can express a command because the <i>kes</i>-phrase can denote an extensional semantic entity as a realistic content of a command. In showing these differences, I propose the semantics of an imperative and an explicit performative as world changers.'
