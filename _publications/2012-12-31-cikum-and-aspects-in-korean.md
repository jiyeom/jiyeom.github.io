excerpt: "**<i>Cikum</i> 'now' and Aspects in Korean** In this paper, I attempt to define the semantics of <i>cikum</i> 'now' in Korean. To define it precisely, we need to look at how it interacts with different aspectual classes of verbs and with the semantics of tenses and aspects. In doing this we need to define the semantics of tenses and aspects. Here we run into the question of whether <i>ess</i> is a tense marker or an aspect marker. I assume that it is ambiguous. There are still cases where it is not clear whether <i>ess</i> is used as a tense marker or an aspect marker in an actual sentence. I discuss two such cases: one in which it is used with verbs like <i>tochakha</i> 'arrive' which have no salient resulting states, and one in which a state verb is used with <i>cikum-kkaci</i> 'until now'. The semantics of <i>cikum</i> can be defined differently depending on whether <i>ess</i> is a tense or an aspect. By discussing <i>ko iss</i>, which is an imperfect marker, I conclude that <i>cikum</i> means λPλi[u⊆i & P(i)], that is, a relation between a set of times which include an utterance time and a set of properties of times."
